# 🪔 નવા વર્ષના રામ રામ - વેલજીભાઈ પાડશાળા (Nava Varsh na Ram Ram)

એક ભવ્ય, દિવ્ય અને હૃદયસ્પર્શી ગુજરાતી ડિજિટલ શુભેચ્છા પત્રિકા (Gujarati New Year Greeting Web Application).
આ વેબસાઇટ ખાસ કરીને **વડીલો (Elderly people)** અને સ્નેહીજનો માટે ઉચ્ચ કોન્ટ્રાસ્ટ, મોટા અક્ષરો, પરંપરાગત હિન્દુ દેવી-દેવતા એનિમેશન, દીવડાઓ અને પવિત્ર મંદિર ઘંટારવ સાથે બનાવવામાં આવી છે.

---

## ✨ મુખ્ય વિશેષતાઓ (Key Features)

1. **પ્રથમ સ્ક્રીન (Cover Screen)**:
   - "॥ શ્રી ગણેશાય નમઃ ॥", "॥ જય શ્રી કૃષ્ણ ॥", "॥ જય સિયારામ ॥" મંગલ સ્તુતિ.
   - **ભગવાન શ્રી કૃષ્ણ અને શ્રી રામ દર્શન એનિમેશન**: ફરતું સુવર્ણ તેજોવલય (Divine Rotating Aura Rays), દિવ્ય પ્રકાશ અને મોરપિચ્છ-મુગુટ સાથેનું ભવ્ય ચિત્ર.
   - મોટા અક્ષરોમાં **"નૂતન વર્ષાભિનંદન - નવા વર્ષના રામ રામ"**.
   - વડીલો માટે ખાસ બનાવવામાં આવેલું મોટું, ઝળહળતું સોનેરી બટન: **"શુભેચ્છા પત્રિકા ખોલો 🪔"**.

2. **બીજી સ્ક્રીન (શુભેચ્છા પત્રિકા - Greeting Card Screen)**:
   - બટન ક્લિક કરતાની સાથે જ **પુષ્પવર્ષા (Flower Petal Shower & Confetti)** અને **પવિત્ર મંદિરની ઘંટડીનો રણકાર (Temple Bell Sound)**.
   - પરંપરાગત કળશ અને શુભ-લાભ મોટિફ.
   - **શ્રી વેલજીભાઈ પાડશાળા તથા સમસ્ત પાડશાળા પરિવાર** તરફથી હાર્દિક મંગલકામનાઓ અને આશીર્વાદ સંદેશ.
   - ઉચ્ચ કોન્ટ્રાસ્ટવાળા મોટા અક્ષરો જે વડીલો પણ સરળતાથી ચશ્મા વગર વાંચી શકે.

3. **ઇન્ટરેક્ટિવ સુવિધાઓ (Interactive Controls)**:
   - 📲 **વોટ્સએપ શેરિંગ (WhatsApp Share)**: એક જ ક્લિકમાં વોટ્સએપ પર સુંદર લખાણ અને લિંક સાથે ફોરવર્ડ કરો.
   - 🌸 **પુષ્પવર્ષા બટન (Flower Shower)**: સ્ક્રીન પર ગલગોટા અને ગુલાબની પાંદડીઓ વરસાવો.
   - 🔔 **મંદિરની ઘંટડી (Temple Bell)**: Web Audio API દ્વારા વાસ્તવિક પિત્તળની ઘંટડીનો પવિત્ર ઘંટારવ (ઓફલાઇન પણ ચાલે છે).
   - 🎵 **ભક્તિ સંગીત (Devotional Ambient Pad)**: શાંત અને આધ્યાત્મિક વાતાવરણ માટે તંબૂરા સંગીત કંટ્રોલ.
   - ↩️ **મુખ્ય પેજ પર પાછા જાઓ (Back Button)**: ફરીથી શરૂઆતથી પત્રિકા જોવા માટે.

## 🚀 વર્સેલ (Vercel) પર ડિપ્લોય કરવાની સરળ રીત

આ એક શુદ્ધ **ફ્રન્ટએન્ડ વેબસાઇટ** (HTML, CSS, JS) છે, જેમાં કોઈ બેકએન્ડ કે ડેટાબેઝની જરૂર નથી. તેથી તે Vercel પર ૧ મિનિટમાં મફત ડિપ્લોય થઈ જાય છે.

### પદ્ધતિ ૧: GitHub & Vercel Dashboard (સૌથી સરળ)
1. તમારા આ પ્રોજેક્ટ ફોલ્ડરને GitHub પર નવી રિપોઝીટરી તરીકે પુશ કરો:
   ```bash
   git init
   git add .
   git commit -m "Nava Varsh na Ram Ram - Veljibhai Padshala Greeting Card"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/nava-varsh-na-ram-ram.git
   git push -u origin main
   ```
2. [Vercel.com](https://vercel.com) પર લૉગિન કરો.
3. **"Add New Project"** પર ક્લિક કરો અને તમારી GitHub repository પસંદ કરો.
4. **Deploy** બટન પર ક્લિક કરો.
5. Vercel તમને એક લિંક આપશે (જેમ કે: `https://nava-varsh-na-ram-ram.vercel.app`).
6. તે લિંક ખોલીને વોટ્સએપ પર બધાને શેર કરો!

### પદ્ધતિ ૨: Vercel CLI દ્વારા ડાયરેક્ટ ડિપ્લોય
જો તમારી પાસે Node.js અને Vercel CLI ઇન્સ્ટોલ કરેલ હોય:
```bash
npm install -g vercel
vercel
```
તમારે ફક્ત `vercel --prod` રન કરવાનું રહેશે.
